## 5 段结构检查（V1.1：60-90 秒版）

### 检查 19：钩子（≤10 字）
- [ ] ≤ 10 字
- [ ] 是 5 类钩子之一（反问/数字/痛点/反着说/案例）
- [ ] 客户 3 秒能 get 到点
- [ ] 不用"赋能/闭环/底层逻辑/战略"

### 检查 20：场景（≤30 字 🆕）
- [ ] ≤ 30 字
- [ ] 有具体客户/具体场景/具体数字
- [ ] 客户能"看到"这个场景
- [ ] 不用"在这种情况下"

### 检查 21：方法/数字（≤50 字 🆕）
- [ ] ≤ 50 字
- [ ] 有具体数字（强度、活性、提产、到货天数、价格）
- [ ] 数字能说服客户（不是自吹）
- [ ] 不用"先进/领先/领导者"
- [ ] 不用"最/第一/唯一/顶级"等极限词

### 检查 22：受益（≤20 字 🆕）
- [ ] ≤ 20 字
- [ ] 是客户视角（不是厂方视角）
- [ ] 客户能"看到"自己受益
- [ ] 不用"我们很好"
- [ ] 不用"根治/100%/包好"等承诺词

### 检查 23：转化（≤10 字）
- [ ] ≤ 10 字
- [ ] 有具体关键词（数据/电费/打样/对比/聊聊）
- [ ] 客户能马上行动
- [ ] 不是"希望/欢迎选购"
- [ ] 不用"微信/vx/二维码/淘宝"

## 数字化检查（必查）

**5 类必填数字**（按内容类型选）：

| 类型 | 必填数字 |
|---|---|
| 提产型 | 提产 X% / 月产 X 吨 |
| 降耗型 | 电耗降 X% / 球耗降 X% / 一吨省 X 度电 |
| 强度型 | 28 天强度提 X MPa / 强度达标率 X% |
| 细度型 | 细度从 X% 降到 X% |
| 省钱型 | 一吨省 X 块 / 一年省 X 万 / X 个月回本 |
| 交期型 | X 天到货 / X 天出数据 / X 天打样 |
| 见证型 | X 客户 X 年 / X 集团 X 个厂 |

**数字三原则**：
1. **真实**：必须是真实数据，不能瞎编
2. **具体**：不要"很多""大量"，要"X 吨""X 万"
3. **对比**：最好有对比（用了前 X / 用了后 Y）

## 客户视角检查（必查）

| 检查项 | 标准 |
|---|---|
| 客户视角 vs 厂方视角 | **客户视角优先**（不用"我们能/我们提供/我们有"）|
| 客户得到什么 | 第 4 段必须是"客户受益"（不是"我们优势"）|
| 客户怕什么 | 痛点钩子要说出客户最怕的事 |
| 客户在意什么 | 数字要落到客户在意的事（省 X 块 / 提 X MPa）|
| 客户决策什么 | CTA 要给客户"能决策的动作"（评论扣 X / 来厂参观）|

## 老板原话检查（额外加分）

老板硬要求：「**口语化，不能有 AI 味**」

**3 个老板原话特征**：

| 特征 | 老板原话示例 | ✅ 用法 |
|---|---|---|
| 江湖气 | "我跟你说"、"对不对"、"说白了"| 文案中可加 1-2 个 |
| 短句断句 | "客户最怕的不是贵，是踩坑" | 老板爱说短句 |
| 反常识 | "你信运气？你得信数据" | 老板爱用反常识钩子 |

**老板的话** = 直接进文案，不改。

## 📌 一句话总结

> **口语化 = 不用 AI 套话 + 用老板原话 + 用数字化指标 + 用客户视角**
> **无违禁词 = 不用 14 类词（极限/承诺/虚假/背书/导流/医疗/金融/教育/迷信/低俗/涉政/未成年/行为/标注）**
> **每条文案出稿前必查 28 项**
> **AI 写出来能拍的不算本事，老板原话 + AI 加工 = 才是真本事**
