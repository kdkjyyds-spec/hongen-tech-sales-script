# 大白话翻译词典（🆕 V1.3 新增）

> **老板反馈**：「专业知识过多，输出的文案要更像口语化，就像给小孩子讲一样」
> **核心原则**：**客户听不懂的词，一个都不要说**
> **用法**：写完脚本 → 逐句检查 → 凡是术语就翻译

---

## 🎯 三条铁律

```
✅ 铁律 1：把客户当"啥也不懂"的人讲（哪怕他是总工，也爱听人话）
✅ 铁律 2：能说"电费"就不说"电耗"，能说"更结实"就不说"强度提升"
✅ 铁律 3：每说一个术语，后面必须跟一句人话解释

❌ 最忌讳：以为客户懂，就用行话（客户嘴上懂，心里烦）
```

## 二、前后对比示例（老板一看就懂）

### 示例 1：产品介绍（专业版 → 大白话版）

**❌ 专业版（客户听着隔一层）**
> "我们的助磨剂采用多元醇胺复合配方，在 0.8% 掺量下可使水泥 28 天抗压强度提升 2.3 MPa，细度（80μm 筛余）从 5% 降至 3.5%，同时降低粉磨电耗 5%。"

**✅ 大白话版（像跟邻居唠嗑）**
> 磨水泥的时候，你加一点点这个——就一小勺的千分之八。
>
> 加了之后有三件事：
>
> 第一，**水泥更结实了**。别人拿你的水泥去盖楼，28 天之后一压，比原来结实一大截，人家挑不出毛病。
>
> 第二，**磨得更细了**。拿筛子一筛，剩下的粗颗粒从 5 斤掉到 3 斤半。一样的水泥，能卖更好的价。
>
> 第三，**电费少了**。磨机不用那么使劲转了，一个月电费能省好几万。

---

### 示例 2：数据报告（专业版 → 大白话版）

**❌ 专业版**
> "本次试验采用 GB/T 17671 标准，掺量 1.0%，3d/28d 抗压强度分别为 28.5/52.3 MPa，同比提升 6.2%/4.6%，筛余降低 1.5%，电耗降低 5.2%。"

**✅ 大白话版**
> 我们给你试了一圈，结果是这样：
>
> · 水泥干了 3 天，比原来结实 6%
> · 干了 28 天，比原来结实 4.6%
> · 磨得更细了，粗颗粒少了一些
> · **最实在的是电费——少了 5% 多，一年下来是几万块**
>
> 数据都在这儿，你可以拿回去自己再验一遍。

---

### 示例 3：服务介绍（专业版 → 大白话版）

**❌ 专业版**
> "我们提供驻厂技术服务，工程师会在您的生产现场进行取样、配方优化及效果跟踪，全程 7-15 天。"

**✅ 大白话版**
> 我们的工程师，**直接住到你厂里**。
>
> 你什么都不用管。他白天看你磨机怎么转、料是什么样，晚上在实验室调配方。
>
> 快的 3 天就出结果，慢的 7 天。
>
> **你不用干活，等着看数据就行。**

---

### 示例 4：客户见证（专业版 → 大白话版）

**❌ 专业版**
> "该客户使用我方产品后，水泥质量稳定性显著提升，客户满意度大幅提高，实现降本增效。"

**✅ 大白话版**
> 这个老板用了半年，跟我说了一句话：
>
> "**以前客户老挑刺，现在一年都没接到过投诉。**"
>
> 他说这话的时候，我看得出来，他心里踏实了。

## 三、大白话自检 5 问（出稿前必问）

```
[ ] 1. 这话我跟我妈说，我妈能听懂吗？
[ ] 2. 有没有让人听不懂的词（强度/MPa/细度/掺量）？
[ ] 3. 说数字的时候，有没有解释这个数字是啥意思？
[ ] 4. 有没有一句"官话"（致力于/赋能/提供优质服务）？
[ ] 5. 通篇读一遍，像不像人平时说话？
```

**5 问全过，才算大白话。**

## 四、术语保留规则（什么时候可以不用翻译）

| 场景 | 用法 |
|---|---|
| 客户是**总工/技术员**，且你俩**私下沟通** | ✅ 可以用术语（他懂，效率高） |
| 拍**短视频**、发**朋友圈**、发**客户群** | ❌ 一律翻译成大白话 |
| 做**正式技术方案/投标文件** | ✅ 用术语（专业度） |
| 短视频**标题/开头** | ❌ 一律大白话（术语没人点） |

🔴 **记忆口诀**：
```
私下聊天可以专业，上台露面必须说人话。
屏幕前的人，永远当他是第一次听说。
```
