# 共情文案库（🆕 V1.3 新增）

> **为什么要有这个？** —— 上面讲的都是"我们有什么"，共情文案讲的是"我懂你难"
> **核心逻辑**：**先共情，再卖货**。客户觉得你懂他，才愿意听你后面说什么
> **适用**：老板 / 工厂老板 / 采购 / 技术员（4 类人的真实难处）
> **用法**：写脚本时，把共情段放在第 1-2 段（钩子 + 场景）

---

## 🎯 共情文案万能公式

```
【第 1 段：共情钩子】"我知道你 X"（说出他的难）
【第 2 段：细说难处】描述他的真实处境（越具体越像他）
【第 3 段：我懂你】"我见过太多这样的老板/采购/技术员"
【第 4 段：不卖货】"我今天不卖你东西，就想跟你说句话"
【第 5 段：转化】"想聊聊的，评论区扣'聊聊'"
```

🟢 **关键**：**共情文案不卖货**。越不卖货，客户越愿意听。

## 一、工厂老板的难处（10 条）

### 痛点清单（真实调研）

| # | 难处 | 大白话 |
|---|---|---|
| 1 | 利润薄如纸 | 卖 100 块，成本 85 块，剩下 5 块多 |
| 2 | 账期长、自己垫钱 | 货拉走了，钱三个月后才到；工资材料还得自己先掏 |
| 3 | 原材料涨价，卖价涨不上去 | 进价天天涨，卖价不敢涨，一涨客户就跑 |
| 4 | 环保、安检、税务天天查 | 一个星期来三拨人，光准备材料就累死 |
| 5 | 招不到人，老员工留不住 | 年轻人不进厂，老师傅留不住 |
| 6 | 大单没了，小单累死 | 一张大单拆成十张小单，换线换到吐 |
| 7 | 同行打价格战 | 你降我也降，最后谁都不挣钱 |
| 8 | 不敢投资、不敢扩产 | 看不清明年，谁敢花钱 |
| 9 | 库存压钱 | 货堆在仓库，钱都压死了 |
| 10 | 晚上睡不着 | 一闭眼就想钱从哪来 |

### 共情文案（10 条）

**1.** 我知道你最近睡不好。
不是身体不好，是心里有事——厂里 100 多号人等着发工资，这个月的订单还没着落。
我见过太多老板，白天笑呵呵，晚上一个人在办公室坐到十二点。
今天不卖你东西，就想跟你说一句：**这会儿难，不是你不行，是大家都难。**

**2.** 厂子卖 100 块，成本 85 块，剩下 5 块多。
这 5 块钱里，还要交税、要留折旧、要准备下个月工资。
别人看你开厂当老板，风光；只有你自己知道，你是在给银行打工、给员工打工。
**老板这活儿，是真不容易。**

**3.** 最怕的不是没订单，是订单一来，账期 90 天。
材料要现钱买，工人工资月底就得发，货拉走了钱得等三个月。
你等于自己掏钱，替客户把活干了。
**这不叫生意，这叫垫钱。**

**4.** 原材料今天一个价，明天又一个价。
你去跟客户谈涨价，客户说"隔壁厂比你便宜 50 块"。
进价天天涨，卖价不敢动——两头一挤，你成了夹心饼干。
**这不是你不会做生意，是行情不由人。**

**5.** 上个月环保来查，这个月安检又来了，下周还有税务。
一个星期三个检查组，光准备材料就忙得脚不沾地。
你想好好干活，可时间全花在应付检查上了。
**理解，真的理解。**

**6.** 以前的单子，一整柜；现在的单子，三五件。
整柜的单子好做，一次开线干到底。现在小单多，一天换三次线，调机调到想砸机器。
**忙得要死，钱没多挣。**

**7.** 同行降价，你跟不跟？
你降，利润没了；你不降，单子跑了。
这不是做生意，这是赌命。
**谁都想挣点钱，可谁都不想让。**

**8.** 前几年还敢投设备、扩厂房，现在谁敢？
看不清明年什么样，投进去的钱，万一打水漂了呢？
**不是不想干，是不敢赌。**

**9.** 仓库里堆着的货，是钱。
压在库里一天，就是一天的利息、一天的折旧、一天的仓储费。
**货卖出去是钱，卖不出去是石头。**

**10.** 我知道你今年难。
大环境不好、利润被挤、收益没涨——这不怪你。
真正要省的不是那几块钱，是**每一吨、每一度电里的那点钱**。
我今天不卖你东西，就想跟你聊聊：**你厂里还有哪些地方能抠出钱来。**

## 二、采购的难处（10 条）

### 痛点清单（真实调研）

| # | 难处 | 大白话 |
|---|---|---|
| 1 | 天生的背锅侠 | 出了事，第一个被问"你选的什么供应商" |
| 2 | 夹心饼干 | 老板要降价，业务要快，两边都得哄 |
| 3 | 催货催到吐血 | 供应商说"周五到"，周四说"下周吧" |
| 4 | 付款慢不敢催 | 公司钱没付，供应商不给发货，只能自己说好话 |
| 5 | 功劳没份，锅是自己的 | 货到了理所应当，货没到自己扛 |
| 6 | 半夜还在比价 | 白天开会，晚上对账，比价看到眼花 |
| 7 | 不敢说"降不动了" | 也不敢说"货真赶不出来" |
| 8 | 流程不齐却要担责 | 老板饭桌上一句话特批，出事时单据上没有 |
| 9 | 采购量小没话语权 | 人家是大客户，你是小客户，说话不硬气 |
| 10 | 天天被怀疑有猫腻 | 干干净净做事，还得被人背后说"油水多" |

### 共情文案（10 条）

**1.** 干采购的都知道一句话：**功劳没你的份，锅都是你的。**
货到了，是销售催得好、生产排得好；货没到，就一句"采购怎么搞的"。
我今天不劝你换供应商，就想跟你说：**你不容易，我看得见。**

**2.** 你最怕的不是加班，是半夜手机响。
供应商说"周五交货"，你信了，系统里更新了。周四你一问，人家轻飘飘一句："原材料没到，下周吧。"
你的血压一下子上来了。但你不能发火——发火，货更没着落。
**这活儿，是真憋屈。**

**3.** 老板天天说"降本降本"，业务天天说"快点快点"。
你夹在中间，左边要省钱，右边要保供，两头都不能得罪。
**这就是"夹心饼干"，谁都懂滋味，谁都不说。**

**4.** 公司账上没钱，供应商不给发货。
你去跟供应商说好话，人家反问一句"你们钱什么时候到"。
你没法答。你只能自己扛着，回来还得跟老板说"我再想想办法"。
**这活儿，表面上是采购，实际上是在中间做和事佬。**

**5.** 最委屈的是这件事：
这供应商是三个部门一起评审通过的，价格是上面定的，交期是业务拍胸脯答应的。
出了事，报告上写的是"采购未把好关"。
**你没吭声，因为你连一份完整的签字记录都拿不出来。**

**6.** 你的难处没人看见。
无数个晚上比价，比到眼花；无数个电话催货，催到嗓子哑；无数趟跑去现场，站到腿麻。
**这些都不算业绩，只有出事的时候，才会有人想起你。**

**7.** 你不敢跟老板说"成本降不动了"，也不敢跟业务说"货真赶不出来"。
说了，就是"你能力不行"。
所以你只能硬撑着，一边算账，一边盯货，找一条谁都能勉强接受的路。
**这活儿，真的累心。**

**8.** 很多人觉得采购"有油水"。
可你清楚：一杯茶、一顿饭、一份心意，都是红线。
你干干净净做事，还得听背后那些话。
**清白的人，最难做。**

**9.** 采购量小的时候，说话是不硬气的。
人家是大客户，你是小客户，想催个货都得陪笑脸。
**理解，这行就是这样。**

**10.** 我知道你昨晚又没睡好。
不是家里有事，是那批货卡在路上了，明天生产就要停。
我今天不卖你东西。我只想说一句：
**你扛的这些，老板不一定知道，但我知道。**

## 三、技术员的难处（10 条）

### 痛点清单（真实调研）

| # | 难处 | 大白话 |
|---|---|---|
| 1 | 白天跑现场，晚上整资料 | 别人下班，你才刚开始干活 |
| 2 | 一人干三个人的活 | 岗位砍掉三成，活儿一点没少 |
| 3 | 出了事第一个被追责 | 质量、安全，第一责任人 |
| 4 | 没话语权 | 技术的事，被不懂技术的人拍板 |
| 5 | 熬五六年还是打杂 | 晋升名额少，轮不到你 |
| 6 | 常年不着家 | 一年在家不到 60 天 |
| 7 | 天天填表报资料 | 干活的时间，全被材料占了 |
| 8 | 经验没人教 | 老师傅忙自己，新人全靠自己摸 |
| 9 | 身体熬坏了 | 失眠、腰疼、胃病 |
| 10 | 干得好没人夸 | 干错了，第一个说你 |

### 共情文案（10 条）

**1.** 干技术这行的，都懂一句话：**日出而作，日落不息。**
白天跑现场，顶着太阳盯质量；晚上回办公室，一整天的资料要写。
别人下班了，你的活儿才刚开始。
**这活儿，不容易。**

**2.** 现在是一个顶三个。
岗位砍了三成，活儿一点没少。
你既要跑现场，又要写资料，还要对接监理、分包、检查。
**不是你能干，是没人了。**

**3.** 最难受的不是累，是出事的时候。
进度慢了，说你技术不到位；质量有瑕疵，说你交底不细；协调出问题，说你沟通不足。
**干得好，是应该的；干错了，第一个说你。**

**4.** 技术上的事，你比谁都懂。
可最后拍板的人，不一定懂技术。
你说这个配方得调，他说"先按原来的来"；你说这个周期不够，他说"客户等不了"。
**话到嘴边，又咽回去了。**

**5.** 熬了五六年，还是干着最基础的活。
不是你不努力，是位置就那么几个。
**这行，熬的是年限，也是心气。**

**6.** 一年到头，在家待不到两个月。
孩子长高了不知道，父母生病了赶不回去。
**你挣的是辛苦钱，亏的是陪家人的时间。**

**7.** 一整天下来，真干活的时间没多少。
填表、报资料、准备检查、反复整改——一圈忙下来，天黑了。
**你想好好干活，可时间不由你。**

**8.** 新人来了没人带。
老师傅自己都忙得脚不着地，没空教你。
你只能自己摸、自己撞，撞得满头包。
**这一路，是硬熬过来的。**

**9.** 熬夜写资料，胃先熬坏了。
腰也疼，觉也睡不好。
**钱是挣到了点，身体是自己的。**

**10.** 我知道你最近心气不高。
活儿多，人少，责任大，钱不多——这四样你全占上了。
我今天不跟你讲技术，就想说一句：
**你干的这些年，值钱。不是没人看见，是没人说。**

## 四、共情文案写作 5 条铁律

```
✅ 铁律 1：第一句必须"我知道你 X"（直接点破他的难）
✅ 铁律 2：细说难处要具体（"四周来三个检查组" 而不是 "检查很多"）
✅ 铁律 3：全文不提产品（越不提，客户越信你）
✅ 铁律 4：用他的原话（"垫钱"卖货"背锅"夹心饼干"）
✅ 铁律 5：结尾给一句暖心的（"你不容易，我看得见"）
```

### ❌ 不要这样写

```
错误："我理解您的处境，我们会提供优质服务"（空话，没有具体难处）
错误："作为供应商，我们深知客户的痛点"（AI 味，客户听着隔一层）
错误："我司致力于为客户创造价值"（官话，一句人话都没有）
```

### ✅ 要这样写

```
✅ "我知道你昨晚又没睡好，不是家里有事，是那批货卡在路上了"
✅ "货到了是理所应当，货没到就一句'采购怎么搞的'"
✅ "白天跑现场，晚上整资料——别人下班了，你的活儿才刚开始"
```

## 五、共情文案怎么用（3 种用法）

### 用法 1：单独发（一周 1 条）
专门发一条纯共情的视频，**不提产品**，只讲"我懂你难"。
→ 效果：评论区会有大量"太真实了""说到我心里了"

### 用法 2：当开头（经常用）
把共情段放在视频开头 20 秒，后面接正常的产品内容。
→ 效果：完播率比直接讲产品高 2-3 倍

### 用法 3：当结尾（偶尔用）
前面讲产品，结尾收一句共情。
→ 效果：让客户觉得"这个销售不光想卖我东西"

🔴 **配比建议**：
```
每周 10 条内容 = 8 条产品 + 2 条共情（纯共情 1 条 + 共情开头 1 条）
```
