## 🛠️ 使用说明

**老板陪跑时**：
1. 销售员说出 1 个原材料（关键词 / 想法 / 感受）
2. 从 5 类钩子中**至少选 3 类**
3. 每类钩子选 1-2 个公式 + 1-3 个例子
4. 输出 **3-5 种不同钩子的版本**

**选择规则**：
- 销售员给"原材料"是关键词 → 优先用**数字钩子**（让关键词变成数字）
- 销售员给"想法" → 优先用**反问钩子**（让想法变成反问）
- 销售员给"感受" → 优先用**痛点钩子**（让感受变成场景）

**最少 3 种钩子组合**（不要都选一类）：

```
推荐组合 1：反问 + 数字 + 案例（最常见）
推荐组合 2：反着来说 + 数字 + 痛点（最强）
推荐组合 3：数字 + 反问 + 反着来说（销售常用）
```
