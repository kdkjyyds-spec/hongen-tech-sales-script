# 5 大拍摄场景

> **每段配 1 个镜头** —— 总时长 30-60 秒，5 段 = 5 个镜头切换
> **使用场景**：第 4 步配拍摄场景

---

## 镜头语言基础（5 大镜头动作）

| 镜头 | 动作 | 适用 | 拍摄难度 |
|---|---|---|---|
| **前推** | 镜头从远到近推 | 介绍产品 / 强调卖点 | ⭐ |
| **后拉** | 镜头从近到远拉 | 介绍环境 / 展示规模 | ⭐ |
| **环绕** | 镜头围绕产品/人物转半圈 | 展示细节 / 360° | ⭐⭐ |
| **定机位** | 镜头不动，人在画面里 | 共情 / 故事 / 转化 | ⭐ |
| **穿梭** | 切换场景时用 | 场景之间切换 | ⭐⭐ |

---

## 场景 1：车间（工程师 / 工人 / 设备）

### 适用内容
- 数字型钩子（提产、降耗、强度）
- 见证型钩子（客户用了之后）

### 镜头设计
| 段 | 镜头 | 拍什么 |
|---|---|---|
| 钩子 | 定机位（销售员）| 销售员站车间入口 |
| 场景 | 后拉（车间全景）| 工程师 / 工人 / 设备 |
| 方法/数字 | 前推（设备特写）| 设备运转 / 数据屏 |
| 受益 | 环绕（销售员+车间）| 销售员走一圈展示车间 |
| 转化 | 定机位 | 销售员正面 |

### 优势
- 真实感最强
- 数字可视化（设备运转 / 数据屏 / 工人操作）
- 适合"提产/降耗"类内容

### 注意
- 戴口罩 / 戴安全帽 / 戴手套（专业感）
- 不要在车间拍老板讲话（不安全）
- 用前推运镜拍设备细节

---

## 场景 2：实验室（小磨实验 / 检测）

### 适用内容
- 数字型钩子（强度、活性、提产）
- 工艺型钩子（配方 / 调优）

### 镜头设计
| 段 | 镜头 | 拍什么 |
|---|---|---|
| 钩子 | 定机位（销售员/工程师）| 工程师站实验室 |
| 场景 | 后拉（实验室全景）| 实验室设备 / 小磨 |
| 方法/数字 | 环绕（实验过程）| 工程师操作实验 |
| 受益 | 定机位（数据报告）| 出具的数据报告 |
| 转化 | 定机位 | 销售员/工程师 |

### 优势
- 专业感最强
- 数据可视化（数据报告 / 实验对比）
- 适合"工艺技术"类内容

### 注意
- 实验室干净 / 设备整齐
- 实验过程可以加速播放（10 秒看完全过程）
- 数据报告要清晰可见

---

## 场景 3：会议室（老板 / 销售员讲解）

### 适用内容
- 共情型钩子（老板共情 / 客户害怕）
- 故事型钩子（老板故事 / 销售员个人）
- 反着来说型钩子

### 镜头设计
| 段 | 镜头 | 拍什么 |
|---|---|---|
| 钩子 | 前推（销售员脸部）| 销售员/老板正面 |
| 场景 | 定机位 | 销售员/老板讲解 |
| 方法/数字 | 前推（手势 / 白板）| 销售员讲解数字 |
| 受益 | 定机位（表情）| 销售员/老板表情 |
| 转化 | 定机位（结束姿势）| 销售员/老板 |

### 优势
- 共情感最强
- 故事讲得最好
- 适合"反着来说 / 老板共情 / 销售员个人"

### 注意
- 背景干净（不要乱糟糟）
- 用手势强调数字
- 表情要到位（真诚）

---

## 场景 4：门口 / 工厂全景（出货 / 装车）

### 适用内容
- 见证型钩子（出货 / 客户来厂）
- 案例型钩子（X 集团 X 个厂）

### 镜头设计
| 段 | 镜头 | 拍什么 |
|---|---|---|
| 钩子 | 后拉（工厂全景）| 工厂门口全景 |
| 场景 | 穿梭（出货过程）| 装车 / 出货过程 |
| 方法/数字 | 环绕（货物特写）| 助磨城装车特写 |
| 受益 | 前推（销售员/司机）| 司机 / 销售员 |
| 转化 | 定机位 | 销售员 |

### 优势
- 信任感最强（看到实际出货）
- 视觉冲击力最强（货车 / 大袋 / 大场景）
- 适合"客户见证 / 大客户"

### 注意
- 选择出货高峰（早上 / 下午）
- 拍大袋 / 大货车（视觉震撼）
- 不要在夜间拍（看不清）

---

## 场景 5：客户现场（客户合影 / 反馈）

### 适用内容
- 案例型钩子（X 客户 X 了 X）
- 见证型钩子（老客户复购）

### 镜头设计
| 段 | 镜头 | 拍什么 |
|---|---|---|
| 钩子 | 定机位（销售员）| 销售员介绍客户 |
| 场景 | 穿梭（客户现场）| 客户工厂 / 客户合影 |
| 方法/数字 | 前推（数据报告）| 客户使用后的数据 |
| 受益 | 定机位（客户反馈）| 客户说话 / 表情 |
| 转化 | 定机位 | 销售员 |

### 优势
- 信任感爆表（客户真实反馈）
- 适合"老客户见证"

### 注意
- **必须客户同意**（签授权）
- 客户说话要真实（不要演）
- 客户形象要正面（不要丑化）

---

## 5 段 × 5 场景 = 25 种组合（速查表）

| 钩子 | 场景 1 车间 | 场景 2 实验室 | 场景 3 会议室 | 场景 4 门口 | 场景 5 客户现场 |
|---|---|---|---|---|---|
| 反问 | ✅ 钩子+场景+转化 | ✅ 钩子+受益 | ✅ 全场景 | ⚠️ 钩子+转化 | ⚠️ 钩子+受益 |
| 数字 | ✅ 全场景（最佳）| ✅ 全场景 | ✅ 全场景 | ✅ 场景+方法 | ✅ 方法+受益 |
| 痛点 | ⚠️ 钩子+受益 | ⚠️ 钩子+受益 | ✅ 全场景（最佳）| ⚠️ 钩子+转化 | ✅ 场景+受益 |
| 反着来说 | ⚠️ 钩子+转化 | ⚠️ 钩子+转化 | ✅ 全场景（最佳）| ⚠️ 钩子+转化 | ✅ 场景+受益 |
| 案例 | ⚠️ 钩子+转化 | ⚠️ 钩子+受益 | ✅ 钩子+受益 | ✅ 全场景（最佳）| ✅ 全场景（最佳）|

**使用规则**：
- 数字 + 车间 = 最佳（数字可视化 + 真实感）
- 反着来说 + 会议室 = 最佳（销售员讲解 + 共情）
- 案例 + 客户现场 = 最佳（真实反馈）

---

## 拍摄 SOP 一句话总结

> **销售员说一段话，剪映切 5 个镜头，每个镜头 5-8 秒——一条视频 30 秒搞定。**
