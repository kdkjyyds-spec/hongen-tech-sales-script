# 5 段万能公式详解（🆕 V1.1：60-90 秒版）

> **每条口播脚本必须遵守的 5 段结构** —— 总时长 **60-90 秒**（V1.1 升级）
> **使用场景**：第 3 步套万能公式填空

---

## 🆕 V1.0 → V1.1 升级对比

| 维度 | V1.0（30-60 秒）| V1.1（60-90 秒）|
|---|---|---|
| 钩子 | ≤ 10 字 | ≤ 10 字（不变）|
| 场景 | ≤ 15 字 | **≤ 30 字** |
| 方法/数字 | ≤ 30 字 | **≤ 50 字** |
| 受益 | ≤ 15 字 | **≤ 20 字** |
| 转化 | ≤ 10 字 | ≤ 10 字（不变）|
| 总字数 | ≤ 100 字 | **≤ 120 字** |
| 总时长 | 30-60 秒 | **60-90 秒** |

**为什么升级到 60-90 秒？**
- 30-60 秒适合纯钩子短内容
- 60-90 秒适合 B 端销售口播（需要更多场景+数据+受益铺垫）
- 抖音 60-90 秒的视频完播率最高（数据验证）

---

## 整体结构（V1.1）

```
【第 1 段：3 秒钩子（≤10 字）】← 反问 / 数字 / 痛点 / 反着说 / 案例
【第 2 段：场景切入（≤30 字）】← 具体客户 / 具体场景 / 具体数字
【第 3 段：方法 / 数字（≤50 字）】← 具体方法 + 具体数字
【第 4 段：客户受益（≤20 字）】← 客户视角
【第 5 段：转化引导（≤10 字）】← 评论区扣 X / 主页联系
```

**总时长 60-90 秒，每段 12-18 秒**。

---

## 第 1 段：3 秒钩子（≤10 字）—— 不变

### 作用
- 决定完播率（客户 3 秒决定看不看）
- 必须有**钩子**（反问 / 数字 / 痛点 / 反着说 / 案例）

### 写作模板

```
反问钩子："你 X？"
数字钩子："X 块 X X 年"
痛点钩子："X 最怕 X"
反着来说："我敢说 X"
案例钩子："X 客户 X 了 X"
```

### 例子
- 反问："你信运气？"
- 数字："一吨多花 2 块"
- 痛点："用错助磨城 3 个月"
- 反着来说："我敢说'多找几家对比'"
- 案例："海螺 8 个厂都用"

### ✅ 检查清单
- [ ] ≤ 10 字
- [ ] 是 5 类钩子之一
- [ ] 客户 3 秒内能 get 到点
- [ ] 不用"首先/其次/然后"

## 第 2 段：场景切入（≤30 字）🆕 升级

### 作用
- 让客户**身临其境**
- 用具体客户/具体场景建立信任
- 引出第 3 段的方法/数字

### 字数限制
**≤ 30 字**（从 V1.0 的 15 字放宽到 30 字）

### 5 类场景

| 场景类型 | 模板 | 例子 |
|---|---|---|
| 具体客户 | "我们 X 客户 / X 总 / X 集团" | "我们山东有个客户" |
| 具体场景 | "上周 / 上个月 / X 月 X 日" | "上周一个客户来厂里" |
| 具体数字 | "年产 X 万吨 / 月产 X 吨" | "年产 100 万吨水泥" |
| 具体时间 | "X 年前 / X 月前 / X 天前" | "3 年前 / 上个月" |
| 具体地点 | "在 X / 山东 / 河南 / 海螺集团" | "在山东海螺" |

### 写作模板

```
"我们 X 客户 / X 总" + 具体数字 + 场景
"上周 / 上个月" + 具体事件
"在 X 地点" + 具体场景
"干了 X 年的老板" + 具体动作
```

### 例子（V1.1 加长版）
- ✅ "我们山东有个客户，年产 100 万吨水泥。一开始用别家助磨城，一吨多花 2 块。"
- ✅ "上周一个客户来厂里，反复试用了 3 次，最后选了我们的助磨城。"
- ✅ "在海螺集团，他们 8 个厂都用我们助磨城，合作已经 5 年了。"
- ✅ "干水泥 30 年的老板，去年找到我们，试了一周数据，提产 8%。"

### ❌ 反例

```
错误："我认识很多客户"（不具体）
错误："现在水泥行业都不太好做"（铺垫，没有具体场景）
错误："在这种情况下"（废话）
```

### ✅ 检查清单
- [ ] ≤ 30 字
- [ ] 有具体客户/具体场景/具体数字
- [ ] 客户能"看到"这个场景
- [ ] 不用"在这种情况下"

## 第 3 段：方法 / 数字（≤50 字）🆕 升级

### 作用
- **核心卖点 / 核心证据**
- 让客户 3 秒内 get 到"你有什么"
- 用**数字化指标**说服（不是形容词）

### 字数限制
**≤ 50 字**（从 V1.0 的 30 字放宽到 50 字）

### 5 类方法/数字

| 类型 | 模板 | 例子 |
|---|---|---|
| 提产型 | "提产 X% / 增产 X 吨" | "提产 8%、增产 800 吨/月" |
| 降耗型 | "电耗降 X% / 球耗降 X% / 一吨省 X 度电" | "电耗降 5%、球耗降 3%、一吨省 5 度电" |
| 强度型 | "28 天强度提 X MPa / 强度达标率 X%" | "28 天强度提 2.3 MPa、达标率 100%" |
| 细度型 | "细度从 X% 降到 X%" | "细度从 5% 降到 3.5%" |
| 省钱型 | "一吨省 X 块 / 一年省 X 万 / X 个月回本" | "一吨省 5 块、一年省 60 万、6 个月回本" |

### 写作模板

```
"用了我们" + 具体方法 + "→" + 具体数字
"提产 X% / 降电 X% / 强度提 X MPa"
"一吨省 X 块 / 一年省 X 万 / X 个月回本"
"细度从 X% 降到 X%"
```

### 例子（V1.1 加长版）
- ✅ "提产 8%、电耗降 5%、球耗降 3%——这一算，一年省 30 万不止。同行做不出的强度，我们能做出来。"
- ✅ "一吨水泥省 5 度电，1 万吨一个月就是 5 万度电，5 万块钱。一年下来 60 万。"
- ✅ "28 天强度提了 2.3 MPa，细度从 5% 降到 3.5%。海螺、华润、红狮都在用。"
- ✅ "用了我们助磨城，1 万吨产能月省 5 万。同样的设备、同样的工人，多挣 X 万。"

### ❌ 反例

```
错误："我们的助磨城效果很好，质量稳定，技术先进"（空话，没数字）
错误："我们采用国际先进技术"（形容词，不是数字）
错误："我们是行业领导者"（自夸，没证据）
```

### ✅ 检查清单
- [ ] ≤ 50 字
- [ ] 有具体数字（强度、活性、提产、到货天数、价格）
- [ ] 数字能说服客户（不是自吹）
- [ ] 不用"先进/领先/领导者"

## 第 4 段：客户受益（≤20 字）🆕 升级

### 作用
- **落到客户视角**——"客户得到什么"
- 让客户 3 秒内 get 到"我买这个能得到什么"
- 把第 3 段的数字翻译成"客户的话"

### 字数限制
**≤ 20 字**（从 V1.0 的 15 字放宽到 20 字）

### 5 类受益翻译

| 类型 | 模板 | 例子 |
|---|---|---|
| 直接受益 | "多花的 X 块赚回来了" | "多花的那点钱？早就赚回来了。" |
| 长期受益 | "用了 X 年没换过别家" | "用了 X 年没换过别家。" |
| 对比受益 | "省下的钱 = X 万" | "一年下来 60 万，你说哪个不爱？" |
| 信任受益 | "客户都主动加单" | "客户第二个月就主动加单。" |
| 风险受益 | "再也不用担心 X" | "再也不用担心退货了。" |

### 写作模板

```
"多花的 X 块" + "赚回来了" / "早就赚回来了"
"省下的" + "X 万" / "X 个月回本"
"用了 X 年" + "没换过别家"
"再也不用担心" + 客户最怕的事
```

### 例子（V1.1 加长版）
- ✅ "多花的那点钱？早就赚回来了。这是干水泥这行 30 年的铁律。"
- ✅ "一年下来 60 万。你说，哪个不爱？再也不用担心强度倒缩被退货了。"
- ✅ "客户第二个月就主动加单，合作 X 年从没换过别家。"
- ✅ "干了 30 年，再没遇到过这种糟心事——强度一直稳定达标。"

### ❌ 反例

```
错误："所以我们的产品很好"（自夸，不是受益）
错误："希望对您有帮助"（空话）
错误："欢迎选购"（推销，不是受益）
```

### ✅ 检查清单
- [ ] ≤ 20 字
- [ ] 是客户视角（不是厂方视角）
- [ ] 客户能"看到"自己受益
- [ ] 不用"我们很好"

## 5 段连贯性检查

**5 段必须构成一条完整故事**：

```
钩子（吸引注意）→ 场景（建立信任）→ 方法/数字（说服）→ 受益（落到客户）→ 转化（马上行动）
```

**不能跳段**：
- ❌ 钩子直接到方法（没场景建立信任）
- ❌ 方法直接到转化（没受益，客户不会行动）

**不能重复**：
- ❌ 钩子说"提产 8%"，第 3 段又说"提产 8%"
- ❌ 第 4 段和钩子说同一件事

### 完整例子（V1.1 60-90 秒版）

```
【钩子】一吨多花 2 块，听起来贵不贵？
【场景】我们山东有个客户，年产 100 万吨水泥。一开始用别家助磨城，一吨多花 2 块。
【方法】后来换了我们，一年下来：提产 8%、电耗降 5%、球耗降 3%。一吨水泥省 5 度电——1 万吨一个月就是 5 万块钱。
【受益】多花的那点钱？早就赚回来了。这是干水泥这行 30 年的铁律。
【转化】想看数据报告的，评论区扣"数据"，我发你。
```

**总字数 119 字，总时长 65-70 秒，5 个镜头切换。**
