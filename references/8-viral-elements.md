## 一、八大爆款元素（8 大元素 × 词根 × 例子）

### 元素 1：成本（花小钱办大事）

| 维度 | 内容 |
|---|---|
| **内核** | 花最少的钱办最大的事 / 最省时 / 最省力 |
| **词根** | 一吨省 X 块 / 一年省 X 万 / X 个月回本 / 省 X% 电 |
| **适用** | B 端采购 / 老板成本压力 / 中小工厂 |

**公式**：
```
"一吨省 X 块" + "1 万吨一个月就是 X 万" + "一年下来 X 万"
"X 个月回本" + "同样的设备同样的工人，多挣 X 万"
"一吨多花 X 块" + "一年省 X 万不止"
```

**例子**：
- ✅ "一吨水泥省 5 度电，1 万吨一个月就是 5 万块钱，一年下来 60 万。"
- ✅ "一吨多花 2 块，听起来贵不贵？后来换了我们，一年省 30 万不止。"
- ✅ "同样的设备、同样的工人，多挣 X 万。"

### 元素 2：人群（某类人的专属）

| 维度 | 内容 |
|---|---|
| **内核** | 弱势群体 / 某类人的专属 / 某类人的痛点 |
| **词根** | "80% 老板不知道" / "干 X 年的老板" / "小工厂" / "刚入行的" |
| **适用** | 精准筛选客群 / 让客户有归属感 |

**公式**：
```
"X% 的 Y 不知道 Z" + 真相
"干了 X 年的 Y，都懂这个道理"
"小 X 也能用上大 Y 同款的 Z"
```

**例子**：
- ✅ "80% 水泥厂老板都不知道的 3 件事。"
- ✅ "干水泥这行 30 年的老板，最近跟我说了一句反思。"
- ✅ "年产能 30 万吨的小水泥厂，也能用上同品质的助磨城。"

### 元素 3：反差（让不适合的人干这事）

| 维度 | 内容 |
|---|---|
| **内核** | 反着说 / 反着做 / 让不该干的人干 / 打破预期 |
| **词根** | "我从不 X" / "别人 X，我 Y" / "我劝你别 X" |
| **适用** | 销售最高级话术 / 建立信任 / 差异化 |

**公式**：
```
"我从不 X" + "但我劝你做 Y"
"别人 X 是为了 A，我 Y 是为了 B"
"我劝你 X" + 反向理由
"我不敢说 X" + "但我敢说 Y"
```

**例子**：
- ✅ "我从不说'用便宜的助磨城'——但我劝老板做一件事。"
- ✅ "我让你先找 5 家对比——别的销售敢吗？"
- ✅ "我不敢说我们最便宜——但敢说 28 天强度稳定达标。"

## 三、5 种反认知开头公式（V1.2 强制）

**每条脚本的开头必须是「反认知」** —— 打破客户的惯性预期。

### 公式 1：反转预期

```
模板："X，听起来不 Y 吧？"
例："一吨水泥省 5 度电，听起来不多吧？"
例："一吨多花 2 块，听起来贵不贵？"
```

**心理效应**：客户预期"省 5 度电不多"，反转后 → "其实一年 60 万"。

### 公式 2：反常识数据

```
模板："X 个老板，Y 个倒在 Z 上"
例："去年 100 个水泥厂老板，有 30 个倒在'降本'上。"
例："80% 老板还在踩这个坑。"
```

**心理效应**：用反常识数据制造震撼。

### 公式 3：悬念 + 信息差

```
模板："X% 人不知道的 Y 件事"
例："80% 水泥厂老板都不知道的 3 件事。"
例："干了 16 年，我帮客户躲过 3 个坑。"
```

**心理效应**：用信息差制造好奇心。

### 公式 4：身份反差 + 悬念

```
模板："X 人跟我说了一句话"
例："我们老板娘在车间干了 30 年，跟我说了一句话。"
例："海螺总工跟我说了一句话。"
```

**心理效应**：身份反差（老板娘/总工）+ 悬念（说了什么）。

### 公式 5：反着说

```
模板："我从不 X" / "别人 X，我 Y"
例："我从不说'用便宜的助磨城'。"
例："我让你先找 5 家对比——别的销售敢吗？"
```

**心理效应**：反着说打破销售刻板印象。

## 四、反认知开头的 3 条铁律

```
✅ 铁律 1：开头第一句必须打破客户预期
✅ 铁律 2：开头 ≤ 10 字（V1.2 保持不变）
✅ 铁律 3：不能用"大家好""今天我想聊聊"这类铺垫
```

### ❌ 反例（不要这样写）

```
错误："大家好，今天跟大家分享一个关于助磨城的话题"（铺垫，不是反认知）
错误："很多客户都在问助磨城哪家好"（问句，但不反认知）
错误："我今天讲 3 个点"（预告，不是反认知）
```

### ✅ 正例

```
✅ "一吨水泥省 5 度电，听起来不多吧？"（反转预期）
✅ "去年 100 个水泥厂老板，有 30 个倒在'降本'上。"（反常识数据）
✅ "80% 老板都不知道的 3 件事。"（悬念+信息差）
✅ "我们老板娘在车间干了 30 年，跟我说了一句话。"（身份反差）
✅ "我从不说'用便宜的助磨城'。"（反着说）
```

## 五、八大元素 + 反认知 = 爆款公式

```
爆款脚本 = 反认知开头（3 秒钩住） 
         + 八大元素（2-3 个 / 条）
         + 5 段结构（60-90 秒）
         + 28 项检查（无违禁词）
```

### 完整示例

```
【反认知钩子】一吨水泥省 5 度电，听起来不多吧？    ← 公式 1（反转预期）
【场景】海螺、华润、红狮都在用我们助磨城。但 3 年前，他们的总工说："你们助磨城一吨多花 2 块，便宜的不敢用。"    ← 头牌元素
【方法】一吨省 5 度电，1 万吨一个月就是 5 万。一年下来 60 万——这是提产 8%、电耗降 5% 之后的结果。    ← 成本元素
【受益】效率上去了，成本自然降，收入自然涨。
【转化】想算你家能省多少，评论区扣"算账"。
```

**元素覆盖**：反认知（公式 1）+ 头牌 + 成本 = **3 个元素** ✅
