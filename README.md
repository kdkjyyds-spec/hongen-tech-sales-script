## 🚀 这个 Skill 解决什么问题

**老板/销售员最难的不是"不知道拍什么"，是"不知道怎么说"。**

场景：
- 销售员现场想到一个点，想马上出一段口播文案
- 老板陪跑客户时，需要根据客户反馈临时写一段
- 挖到一条客户金句，要做成 60-90 秒的口播脚本

**这个 Skill 就是干这件事的** —— 你给 1 个想法，它给 10 条能直接拍的口播文案。

| 能力 | 说明 |
|---|---|
| **输入** | 销售给 1 个关键词 / 1 句话想法 / 1 段感受 |

| **直接拍** | ✅ 5 段结构 + 5 个镜头建议 + 28 项检查清单 |

## 🔧 6 步使用流程

```
第 1 步：接收销售给的"原材料"（关键词 / 想法 / 感受）
第 2 步：选 5 类钩子（反问 / 数字 / 痛点 / 反着说 / 案例）
第 3 步：套 5 段万能公式（钩子 + 场景 + 方法/数字 + 受益 + 转化）
第 4 步：配 5 大拍摄场景（车间 / 实验室 / 会议室 / 门口 / 客户现场）
第 5 步：查 14 类违禁词 + 8 大爆款元素 + 反认知开头
第 6 步：交付 10 条版本
```

---

## 📐 5 段万能公式（60-90 秒）

```
【第 1 段：3 秒钩子（≤10 字）】← 反认知开头（反转预期/反常识数据/悬念/身份反差/反着说）
【第 2 段：场景切入（≤30 字）】← 具体客户 / 具体场景 / 具体数字
【第 3 段：方法 / 数字（≤50 字）】← 具体方法 + 具体数字
【第 4 段：客户受益（≤20 字）】← 客户视角
【第 5 段：转化引导（≤10 字）】← 评论区扣 X / 主页联系
```

**总字数 ≤ 120 字，总时长 60-90 秒**。

## 🧬 八大爆款元素

| # | 元素 | 内核 | 词根示例 |
|---|---|---|---|
| 1 | **成本** | 花小钱办大事 | 一吨省 X 块 / 一年省 X 万 |
| 2 | **人群** | 某类人的专属 | "80% 老板不知道" |
| 3 | **反差** | 反着说 / 打破预期 | "我从不 X" |
| 4 | **奇葩** | 极大 / 极小 / 极快 | "80% 不知道的 3 个真相" |
| 5 | **最差** | 买完必后悔 | "赔了 50 万" |
| 6 | **怀旧** | 20 年前 / 当年经典 | "干 30 年的反思" |
| 7 | **头牌** | 名人 / 名企同款 | "X、Y、Z 都在用" |
| 8 | **荷尔蒙** | 男女话题 / 情感 | "老板娘在车间干了 30 年" |

**每条脚本至少 2-3 个元素，10 条脚本必须覆盖全部 8 个。**

## 🎯 使用示例

### 输入（销售给的想法）

> "水泥厂老板不容易，因为降本增效，必须在成本上下功夫。什么是成本？其实提高做模的效率就是降了，就是提高收入。"

### 输出（10 条脚本，示例 1 条）

```
【钩子】一吨水泥省 5 度电，听起来不多吧？
【场景】海螺、华润、红狮都在用我们助磨城。但 3 年前，他们的总工说：
        "你们助磨城一吨多花 2 块，便宜的不敢用。"
【方法】一吨省 5 度电，1 万吨一个月就是 5 万。一年下来 60 万——
        这是提产 8%、电耗降 5% 之后的结果。
【受益】效率上去了，成本自然降，收入自然涨。
【转化】想算你家能省多少，评论区扣"算账"。

元素：成本 + 头牌 | 反认知：反转预期 | 时长：65-70 秒 | 28 项检查：全过
```

**其余 9 条见 `references/10-scripts-v1.2.md`。**

## ⚠️ 边界（什么不做）

- ❌ 不替老板做不可逆决定（接单 / 解雇 / 融资等）
- ❌ 不做法律 / 财务 / 税务咨询
- ❌ 不替销售员给客户做承诺（必须真实数据）
- ❌ 不写"最 / 第一 / 唯一"等极限词
- ❌ 不写"微信 / vx / 二维码"等导流词
- ✅ 保留老板 / 销售员最终决定权
- ✅ 必须用"客户视角"写
